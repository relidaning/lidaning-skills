# Sessions

## 2026-09-24 — Build skill-bench and run its first benchmarks
Built `skill-bench` from scratch (`bench.py` harness, SKILL.md, CARD template, registered + project-installed, added to repo CLAUDE.md/README) and ran frozen v1.0.0 suites: `context-summarize` PASS (36/36 trigger, 87.5% behavior, only +0.8% over the no-skill baseline once the uplift calc was fixed) and `skill-bench` itself trigger-only PASS (30/30); both blind label audits were applied before freezing (the ambiguous "score X" case was replaced; a suite-wide `reply_strip_regex` was added so english-practice blocks don't pollute checks). ## 2026-09-26 — Harden the harness and make its numbers honest
Goal session ("optimize my benchmark skill until satisfied"). Fixed correctness bugs: `--resume` used current flags instead of the original run's (could mix models or drop baseline trials), resumed runs duplicated their history row, harness-crashed trials lost their model and vanished from error counts, judge cost was never counted and judge output never saved, and same-second runs shared a run dir. Changed the no-skill baseline from disabling the whole Skill tool to denying only `Skill(<target>)`, after a live trial showed the baseline reply apologizing for missing english-practice and being penalized for it (`baseline_mode` recorded). Stats are now case-level (case-Wilson recall/FPR, case bootstrap for F1/score/uplift), uplift is paired with a significance flag, and reports and the dashboard gained a "read before trusting the verdict" block (n.s. uplift, non-discriminating behavior cases, too few cases to certify thresholds, saturation), a by-claim table, paired run-to-run deltas, and a model picker. `validate` now checks claim coverage against the CARD and already found context-summarize's untested B2. Added `selftest.py` (offline, fake `claude`, 26 checks, mutation-verified). skillopt now gates on skill-bench suites when they exist. Two small real runs (~$1.30 total, dev split, kept out of history) verified the judge and baseline changes live.
